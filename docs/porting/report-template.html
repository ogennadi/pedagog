Pedagog engine.ts: types and functions

This lists every type and named function in engine.ts, section by section, with signatures in domain names (Square, Board, Pv…). Names are in bold so the list can be scanned. The grey stored as line under an entry gives the concrete representation where it matters. Functions nested inside another function, and the methods of a class, are numbered under it (20.1). Every interface field is readonly unless the entry says otherwise.

  • The sentinels have names: NO_MOVE (0), NO_SQUARE (−1), EMPTY (0) and NO_LINE (an empty, frozen array).

Types

In alphabetical order.

  1. T1type Board = Int8Array 128 entries: a Piece per Square.
  2. T2interface Castle { castlingRookSquare: Int32Array; castlingRightsMask: Int8Array } The castling geometry of one game: each right’s rook square (by Right), and the rights that survive a move from or to each square. All positions in a game share one.
  3. T3type Colour = typeof WHITE | typeof BLACK The side to move or a piece’s owner: 0 or 1.
  4. T4class Draft { board: Board; pieceCount: PieceCounts; kingSq: [Square, Square]; key: Key } The scratch copy that makeMove turns into the next position. Its board, piece counts, king squares and key change together, through lift and put (44). The arrays are fresh copies; key is mutable.
  5. T5type File = number A square’s file, 0–7 (a = 0).
  6. T6type Go = { [K in GoNumber]?: number } & { infinite?: boolean } A parsed “go” command: whichever of those numbers it gave, plus infinite.
  7. T7type GoNumber = typeof GO_NUMBERS[number] The name of a number a “go” command may carry: wtime, btime, winc, binc, movestogo, depth, nodes or movetime.
  8. T8type Index64 = number A square from 0 (a1) to 63 (h8), whatever the board layout.
  9. T9interface Io { out(line: string): void; now(): Millis; shouldStop(): boolean } How uciCommand talks to the world: output, a clock and a stop request.
  10. T10type Key = number A 32-bit Zobrist key, held as a signed 32-bit integer.
  11. T11type KingSquares = readonly [Square, Square] Each colour’s king square.
  12. T12interface Limits { depth: number; nodes: number; softMs: Millis; hardMs: Millis } How far and how long to search. After softMs no new depth starts; at hardMs the search is cut off. nodes 0 means no limit.
  13. T13interface Line { score: Score; pv: Pv } A score and the line of best play that produces it.
  14. T14type Millis = number Milliseconds.
  15. T15type Move = number A packed move: from, to, promotion and move type. No move encodes as 0, NO_MOVE. It stays a plain number, so a Pv is an array of numbers, not of objects.
  16. T16type MoveType = number How a move is made: normal, FLAG_EP or FLAG_CASTLE.
  17. T17type Piece = number A piece type plus colour << 3, or EMPTY.
  18. T18type PieceCounts = Int8Array 16 entries: a count per Piece.
  19. T19type PieceType = number Pawn (PAWN 1) to king (KING 6).
  20. T20interface Position { board: Board; kingSq: KingSquares; pieceCount: PieceCounts; sideToMove: Colour; castlingRights: Rights; castle: Castle; epSquare: Square; halfmoveClock: number; key: Key; gamePly: number; capturedPiece: Piece; previous: Position | null } An immutable position. previous links to the position before the last move (null at the start), which is all repetition detection needs. capturedPiece is the piece the last move took from its destination square (EMPTY for en passant).
  21. T21type PsqTable = Int16Array 16 × 64 entries, indexed piece * 64 + index64(sq).
  22. T22type Pv = readonly Move[] A line of moves, best play first.
  23. T23type Rank = number A square’s rank, 0–7 (rank 1 = 0).
  24. T24interface Result { bestMove: Move; depth: number; score: Score; nodes: number; elapsed: Millis; pv: Pv } One finished depth: the move to play, its score and the line of best play behind it.
  25. T25type Right = number One castling right, 0–3: white kingside, white queenside, black kingside, black queenside.
  26. T26type Rights = number A 4-bit set of Rights.
  27. T27interface Rung { depth: number; deeperPermille: number; blunderWindow: Score; blunderPermille: number; vision: number } One level’s knobs. Both ladders are readonly Rung[], level n at index n − 1. Level 1’s row is all zeros, because the random mover ignores its knobs.
  28. T28type Score = number Centipawns for the side to move.
  29. T29class Search { limits; skill; io; unseen: Pv; startTime: Millis; nodes: number; stopped: boolean; rootDepth: number } The working state of one think call. Only nodes, stopped and rootDepth change; it is the only mutable state the search has. Its methods are under 20.
  30. T30interface SearchIo { now(): Millis; shouldStop(): boolean; onInfo(result: Result): void } What think needs from the world: a clock, a stop request and a place to report each depth.
  31. T31interface Session { pos: Position; skill: Skill; chess960: boolean } Everything the engine remembers between UCI commands.
  32. T32interface Skill extends Rung, Style { level: number; seed: number; aggressive: boolean; seedKey: number } One seeded opponent: a level’s rung combined with a style. Made by skillFor and frozen. seedKey is the seed, hashed.
  33. T33type Square = number A 0x88 index (0–127), or NO_SQUARE.
  34. T34interface Style { kingAttack: Score; materialMg: number; checkBias: Score } A playing style (aggressive or plain): a bonus for pieces near the enemy king, a discount on middlegame material, and a preference for checks at the root.

  18. 18now(): Millis Milliseconds from a high-resolution clock.

S1 Search

  1. 19think(pos: Position, limits: Limits, skill: Skill, io: SearchIo): Result Picks a move. It searches one depth deeper each time until a limit is hit, reporting each finished depth. Level 1 plays a random move instead. bestMove is NO_MOVE when there is no legal move.
  2. 20class Search The working state of one think call (see the type).
    1. 20.1new Search(limits: Limits, skill: Skill, io: SearchIo, unseen: Pv, startTime: Millis) Starts with no nodes counted.
    2. 20.2root(pos: Position, depth: number, hint: Pv): Line One iteration of think: the root searched to depth, trying hint, the previous depth’s best line, first.
    3. 20.3search(pos: Position, alpha: Score, beta: Score, depth: number, ply: number, hint: Pv): Line Negamax alpha-beta search to a fixed depth. It skips moves the skill fails to notice, and tries the previous depth’s best line first.
    4. 20.4qsearch(pos: Position, alpha: Score, beta: Score, ply: number, pliesLeft: number): Score Quiescence search: follows captures at a leaf until the position is quiet, at most pliesLeft deep.
    5. 20.5overlooks(next: Position, move: Move, ply: number): boolean Whether the player fails to notice a move. At the root the overlooked moves were chosen in advance; deeper, seesMove decides.
    6. 20.6checkBias(next: Position, ply: number): Score At the root, the style’s bonus for a move that gives check; otherwise 0.
    7. 20.7countNodeAndCheckStop(): boolean Counts a node and, every 1,024 nodes from depth 2 on, checks the limits. Returns whether to stop.
    8. 20.8limitReached(): boolean The node limit or hard time limit has been reached, or a stop has been asked for.
  3. 21isMateScore(score: Score): boolean Whether a score is a mate score rather than an evaluation.
  4. 22orderMoves(pos: Position, moves: Pv, pvMove: Move): Move[] Returns the moves in a new order: the previous depth’s best move, then captures by MVV-LVA, then quiet moves.
  5. 23isCapture(pos: Position, move: Move): boolean Whether the move takes a piece or promotes. Castling does not count.
  6. 24capturesByValue(pos: Position, moves: Pv): Move[] Just the captures and promotions, highest captureScore first. The sort is stable.
  7. 25captureScore(pos: Position, move: Move): number The MVV-LVA key: ten times the victim’s value, plus any promotion, minus the attacker’s value.
  8. 26limitsFor(go: Go, side: Colour, level: number): Limits Turns a “go” command into search limits. Only the top level reads the clock; it keeps a one-second reserve.

S2 Skill levels

  1. 27rung(depth: number, deeperPermille: number, blunderWindow: Score, blunderPermille: number, vision: number): Rung Builds one ladder rung; each argument is one knob.
  2. 28skillFor(level: number, seed: number, aggressive: boolean): Skill The frozen skill for a level (clamped to 1–10), a seed and a style.
  3. 29depthFor(pos: Position, skill: Skill): number The depth limit for this position: the rung’s depth, plus one on a hashed share of positions.
  4. 30judge(pos: Position, skill: Skill): Score The evaluation in the skill’s style plus any blunder. This is what the search scores a leaf with.
  5. 31blunder(pos: Position, skill: Skill): Score The occasional misjudgement: on a hashed share of positions, up to ±blunderWindow centipawns.
  6. 32seesMove(after: Position, skill: Skill, move: Move, ply: number): boolean Whether the player notices a move. Vision fades with ply, and captures and checks get a second chance.
  7. 33overlookedRootMoves(pos: Position, skill: Skill, rootMoves: Pv): Move[] The root moves the player misses. If it would miss every one, it sees them all.
  8. 34randomMove(pos: Position, skill: Skill, moves: Pv): Move Level 1’s move: mate in one if there is one, otherwise a hashed random choice.
  9. 35givesMate(pos: Position, move: Move): boolean Whether a legal move checkmates.
  10. 36mix32(x: number): number A 32-bit integer hash finaliser that scrambles bits. Returns an unsigned 32-bit number.

S3 Evaluation

  1. 37psqBonus(pieceType: PieceType, f: File, r: Rank): readonly [mg: Score, eg: Score] The placement bonus for a white piece of this type on this file and rank, for the middlegame and the endgame.
  2. 38pieceSquareTables(): readonly [mg: PsqTable, eg: PsqTable] Tables of psqBonus for every piece and square. Black’s are mirrored with flipRank and negated.
  3. 39kingDistances(): Int8Array King moves between any two squares, 64 × 64 entries indexed index64(a) * 64 + index64(b).
  4. 40evaluate(pos: Position, style: Style): Score Static evaluation in centipawns for the side to move: material, placement and the style’s king-attack term, tapered from middlegame to endgame. It walks SQUARES.

S4 Chess rules and position

  1. 41castlingRight(colour: Colour, kingside: boolean): Right A colour’s kingside or queenside right.
  2. 42hasRight(rights: Rights, right: Right): boolean Whether a castling right is held.
  3. 43isKingside(right: Right): boolean Whether a castling right is kingside.
  4. 44class Draft The scratch copy makeMove works on (see the type).
    1. 44.1new Draft(pos: Position) Copies the board, piece counts, king squares and key.
    2. 44.2lift(sq: Square): Piece Takes a piece off a square and returns it, keeping the counts and key in step.
    3. 44.3put(sq: Square, piece: Piece): void Puts a piece on an empty square, keeping the counts, king squares and key in step.
  5. 45makeMove(pos: Position, move: Move): Position | null The position after a move, or null if it leaves the mover’s king in check. pos is not changed.
  6. 46makeLegalMove(pos: Position, move: Move): Position For callers that already know the move is legal, so they need no null check. Throws otherwise.
  7. 47inCheck(pos: Position): boolean Whether the side to move is in check.
  8. 48isDraw(pos: Position): boolean A draw by the fifty-move rule, a repetition or insufficient material. The repetition walk is bounded by min(halfmoveClock, gamePly).
    1. 48.1count(pieceType: PieceType): number How many pieces of a type both sides have together.
  9. 49words(line: string): string[] The words of a line, split at runs of whitespace.
  10. 50toInteger(text: string | undefined, fallback: number): number text as a whole decimal integer, or fallback if it is not one.
  11. 51parseFen(fen: string): Position A new position, with no history, from a FEN string.
  12. 52castlingFromFen(board: Board, kingSq: KingSquares, field: string): { castlingRights: Rights; castle: Castle } Reads the FEN castling field in KQkq, Shredder-FEN or X-FEN form, so Chess960 is covered.
    1. 52.1outermostRook(rank: Rank, rook: Piece, edge: File, kingFile: File): File The file of the outermost rook between the edge and the king, or −1.
  13. 53toFen(pos: Position, chess960: boolean): string The position as a FEN string. Castling rights are written as file letters only for Chess960 rooks that are not in the corners.
  14. 54moveToUci(move: Move, chess960: boolean): string A move in UCI notation, such as “e2e4”. Castling is written king-takes-rook in Chess960.
  15. 55parseMove(pos: Position, str: string, chess960: boolean): Move The legal move written as str, or NO_MOVE. Castling is accepted in either notation.
  16. 56legalMoves(pos: Position): Move[] The legal moves, as a new array.
  17. 57isSlider(pieceType: PieceType): boolean Whether a piece type keeps stepping along its rays: bishop, rook or queen.
  18. 58generateMoves(pos: Position): Move[] The pseudo-legal moves; makeMove checks king safety. Pawns advance by PAWN_STEP; other pieces use PIECE_OFFSETS.
    1. 58.1pawnMove(from: Square, to: Square, type: MoveType): void Adds a pawn move to the list, expanding a move to the last rank into its four promotions.
  19. 59isSquareAttacked(board: Board, sq: Square, by: Colour): boolean Whether a colour attacks a square. It looks outward from the square; SLIDER_RAYS says which sliders attack along each ray.

S5 Zobrist hashing

  1. 60xorshift32(x: number): number The next state of a 32-bit xorshift generator.
  2. 61zobristKeys(seed: number): { zobPiece; zobCastle; zobEp; zobSide: Key } stored as views of one Int32Array of 1,049 draws: 16 × 64 by piece * 64 + index64, 16 by Rights, 8 by File, then the side The random numbers that are XORed into a position’s key, drawn in a fixed order from a fixed-seed generator, so every machine gets the same keys.

S6 UCI

  1. 62isGoNumber(word: string): word is GoNumber Type guard: whether a word is one of the numbered “go” fields.
  2. 63newSession(): Session The starting position at level 10, aggressive, not Chess960.
  3. 64uciCommand(session: Session, line: string, io: Io): Session Handles one UCI command line and returns the session for the next one.
    1. 64.1onInfo(info: Result): void Prints a UCI “info” line for each depth that finishes during “go”.
  4. 65parsePosition(spec: string, chess960: boolean): Position The position from the arguments of a “position” command: “startpos” or a FEN, then any moves. Unknown moves are skipped.
  5. 66parseGo(tokens: readonly string[]): Go The numbers and flags of a “go” command. Unknown words are skipped.
  6. 67infoLine(result: Result, chess960: boolean): string The UCI “info” line for one finished depth.
  7. 68perft(pos: Position, depth: number): number Counts the leaf nodes to a depth, as a test of the move generator.
  8. 69perftDivide(pos: Position, depth: number, chess960: boolean, io: Io): void Prints the perft count under each root move, then the total and the speed.
  9. 70bench(depth: number, io: Io): void Searches a fixed set of positions at level 10. The total node count is the signature OpenBench reads.
    1. 70.1shouldStop(): false Never stops the search.
    2. 70.2onInfo(): void Discards the per-depth reports.
  10. 71printBoard(pos: Position, skill: Skill, chess960: boolean, out: (line: string) => void): void The “d” command: prints the board, FEN, key and evaluation.

  3. 74Worker Keeps the session and runs uciCommand for each line it receives.
    1. 74.1io.out(line: string): void Posts a line to the main thread.
