pedagog engine.ts: types and functions

This lists every type and named function that ports/typescript/engine.ts would have after applying ports/readability-notes.md. It is a proposal: the TypeScript file has not been changed yet. Signatures use domain names (Square, Board, Pv…). The grey stored as line under an entry gives the concrete representation where it matters. Functions nested inside another function are numbered under it (15.1). Every interface field is readonly unless the entry says otherwise.

  • new a function or type the notes add.
  • The sentinels have names: NO_MOVE (0), NO_SQUARE (−1), EMPTY and NO_LINE (empty, frozen array).

Domain names

TypeScript has type aliases, so the proposal declares every name below in engine.ts, and the signatures in this report are the code. Aliases of number are not branded: the checker accepts a Square where a Piece is expected, so the names document intent rather than enforce it. Tables stay typed arrays, which engines store unboxed.

  • Board = Int8Array, 128 entries: a Piece per Square.
  • Colour = typeof WHITE | typeof BLACK (0 or 1).
  • DistanceTable = Int8Array, 64 × 64 entries, indexed a * 64 + b by Index64.
  • File, Rank = number, 0–7.
  • Index64 = number, 0–63, layout-free (see 10).
  • Key = number, a 46-bit Zobrist key (exact in a double).
  • KingSquares = readonly [Square, Square], by Colour.
  • Millis = number, milliseconds.
  • Move = number, packed from, to, promotion and move type.
  • MoveType = number: normal, FLAG_EP or FLAG_CASTLE.
  • Piece = number, type plus colour × 8, or EMPTY.
  • PieceCounts = Int8Array, 16 entries: a count per Piece.
  • PieceType = number: PAWN 1 to KING 6.
  • PsqTable = Int16Array, 16 × 64 entries, indexed piece * 64 + index64.
  • Pv = readonly Move[], a line of moves, best play first.
  • Right = number, one castling right, 0–3.
  • Rights = number, a 4-bit set of Rights.
  • Score = number, centipawns for the side to move.
  • Square = number, a 0x88 index (0–127), or NO_SQUARE.

Types

In alphabetical order.

  1. T1type Board = Int8Array new 128 entries: a Piece per Square.
  2. T2interface Castle { castlingRookSquare; castlingRightsMask } stored as Int32Array (4, by Right) and Int8Array (128, a Rights per Square) The castling geometry of one game: each right’s rook square, and the rights that survive a move from or to each square. All positions in a game share one. The fields were rookSq and mask.
  3. T3type Colour = typeof WHITE | typeof BLACK The side to move or a piece’s owner: 0 or 1.
  4. T4type DistanceTable = Int8Array new 64 × 64 entries, indexed a * 64 + b by Index64.
  5. T5interface Draft { board: Board; pieceCount: PieceCounts; kingSq: [Square, Square]; key: Key } new fresh copies; key is mutable The scratch copy that makeMove turns into the next position. Its board, piece counts, king squares and key change together.
  6. T6type File = number new A square’s file, 0–7.
  7. T7type Go = { [K in GoNumber]?: number } & { infinite?: boolean } A parsed “go” command: whichever of those numbers it gave, plus infinite. A missing number is tested with in, not compared with undefined.
  8. T8type GoNumber = typeof GO_NUMBERS[number] The name of a number a “go” command may carry: wtime, btime, winc, binc, movestogo, depth, nodes or movetime.
  9. T9type Index64 = number new A square from 0 (a1) to 63 (h8), whatever the board layout.
  10. T10interface Io { out(line: string): void; now(): Millis; shouldStop(): boolean } How uciCommand talks to the world: output, a clock and a stop request.
  11. T11type Key = number new A 46-bit Zobrist key (exact in a double).
  12. T12type KingSquares = readonly [Square, Square] new Each colour’s king square.
  13. T13interface Limits { depth: number; nodes: number; softMs: Millis; hardMs: Millis } How far and how long to search. After softMs no new depth starts; at hardMs the search is cut off.
  14. T14interface Line { score: Score; pv: Pv } A score and the line of best play that produces it.
  15. T15type Millis = number new Milliseconds.
  16. T16type Move = number A packed move: from, to, promotion and move type. It stays a plain number, so a Pv is an array of numbers, not of objects.
  17. T17type MoveType = number new How a move is made: normal, FLAG_EP or FLAG_CASTLE.
  18. T18type Piece = number A piece type plus colour × 8, or EMPTY.
  19. T19type PieceCounts = Int8Array new 16 entries: a count per Piece.
  20. T20type PieceType = number new Pawn (PAWN 1) to king (KING 6). It keeps a piece type apart from a Piece, as Stockfish, Gaia and Tiny Chess Bot do.
  21. T21interface Position { board: Board; kingSq: KingSquares; pieceCount: PieceCounts; sideToMove: Colour; castlingRights: Rights; castle: Castle; epSquare: Square; halfmoveClock: number; key: Key; gamePly: number; capturedPiece: Piece; previous: Position | null } An immutable position. The renamed fields were side, castling, epSq, fifty, plies, captured and prev. previous is still null at the start, but nothing reads it there, because isDraw walks back at most min(halfmoveClock, gamePly) plies.
  22. T22type PsqTable = Int16Array new 16 × 64 entries, indexed piece * 64 + index64.
  23. T23type Pv = readonly Move[] new A line of moves, best play first.
  24. T24type Rank = number new A square’s rank, 0–7.
  25. T25interface Result { bestMove: Move; depth: number; score: Score; nodes: number; elapsed: Millis; pv: Pv } One finished depth: the move to play, its score and the line of best play behind it.
  26. T26type Right = number new One castling right, 0–3.
  27. T27type Rights = number new A 4-bit set of Rights.
  28. T28interface Rung { depth: number; deeperPermille: number; blunderWindow: Score; blunderPermille: number; vision: number } One level’s knobs. Both ladders are readonly Rung[], level n at index n − 1, with no null. Level 1’s row is all zeros, because the random mover ignores its knobs.
  29. T29type Score = number new Centipawns for the side to move.
  30. T30interface SearchIo { now(): Millis; shouldStop(): boolean; onInfo(result: Result): void } What think needs from the world: a clock, a stop request and a place to report each depth.
  31. T31interface SearchRun { nodes: number; stopped: boolean; rootDepth: number } new fields are mutable The working state of one think call. Only these fields change; it is the only mutable state the search has.
  32. T32interface Session { pos: Position; skill: Skill; chess960: boolean } Everything the engine remembers between UCI commands.
  33. T33interface Skill extends Rung, Style { level: number; seed: number; aggressive: boolean; seedKey: number } One seeded opponent: a level’s rung combined with a style. Made by skillFor and frozen.
  34. T34type Square = number A 0x88 index (0–127), or NO_SQUARE.
  35. T35interface Style { kingAttack: Score; materialMg: number; checkBias: Score } A playing style (aggressive or plain): a bonus for pieces near the enemy king, a discount on middlegame material, and a preference for checks at the root.

Functions

S0 Constants and the board layout

  1. 1opponent(colour: Colour): Colour The other side.
  2. 2typeOf(piece: Piece): PieceType new A piece’s type, pawn to king.
  3. 3colourOf(piece: Piece): Colour new A piece’s colour.
  4. 4makePiece(pieceType: PieceType, colour: Colour): Piece new A packed piece.
  5. 5fileOf(sq: Square): File new A square’s file, 0–7.
  6. 6rankOf(sq: Square): Rank new A square’s rank, 0–7.
  7. 7makeSquare(file: File, rank: Rank): Square new The square on a file and rank.
  8. 8onBoard(sq: Square): boolean new Whether a square is on the board.
  9. 9flipRank(sq: Square): Square new The same square seen from black’s side.
  10. 10index64(sq: Square): Index64 new A square’s index from 0 to 63, used by the Zobrist keys, the piece-square tables and the king distances, so they work with any board layout. (The seesMove hash keeps the raw move bits, so its choices stay the same.)
  11. 11fromSq(move: Move): Square The square the move starts from.
  12. 12toSq(move: Move): Square The square the move goes to. For castling this is the rook’s square.
  13. 13promoType(move: Move): PieceType The piece type promoted to, or 0.
  14. 14moveType(move: Move): MoveType The kind of move: normal, en passant or castling.
  15. 15encodeMove(from: Square, to: Square, promoType: PieceType, moveType: MoveType): Move Packs the four parts into one move.
  16. 16squareName(sq: Square): string A square’s algebraic name, such as “e4”.
  17. 17parseSquare(str: string): Square The square named by “e4” and the like.
  18. 18now(): Millis Milliseconds from a high-resolution clock.

S1 Search

  1. 19think(pos: Position, limits: Limits, skill: Skill, io: SearchIo): Result Picks a move. It searches one depth deeper each time until a limit is hit, reporting each finished depth. Level 1 plays a random move instead. Its nested functions share one SearchRun.
    1. 19.1countNodeAndCheckStop(): boolean new Counts a node and, every 1,024 nodes from depth 2 on, checks the limits. Returns whether to stop.
    2. 19.2limitReached(): boolean The node limit or hard time limit has been reached, or a stop has been asked for.
    3. 19.3search(pos: Position, alpha: Score, beta: Score, depth: number, ply: number, hint: Pv): Line Negamax alpha-beta search to a fixed depth. It skips moves the skill fails to notice, and tries the previous depth’s best line first.
    4. 19.4qsearch(pos: Position, alpha: Score, beta: Score, ply: number, pliesLeft: number): Score Quiescence search: follows captures at a leaf until the position is quiet.
  2. 20orderMoves(pos: Position, moves: Pv, pvMove: Move): Move[] Returns the moves in a new order: the previous depth’s best move, then captures ordered by MVV-LVA, then quiet moves.
  3. 21isCapture(pos: Position, move: Move): boolean Whether the move takes a piece or promotes. Castling does not count.
  4. 22capturesByValue(pos: Position, moves: Pv): Move[] Just the captures and promotions, ordered by MVV-LVA (most valuable victim, then least valuable attacker). The sort is stable.
    1. 22.1victim(move: Move): PieceType The type of the piece captured.
    2. 22.2gain(move: Move): number The MVV-LVA sort key.
  5. 23limitsFor(go: Go, side: Colour, level: number): Limits Turns a “go” command into search limits. Only the top level reads the clock; it keeps a one-second reserve. It tests for the clock with "wtime" in go.

S2 Skill levels

  1. 24rung(depth: number, deeperPermille: number, blunderWindow: Score, blunderPermille: number, vision: number): Rung Builds one ladder rung; each argument is one knob.
  2. 25skillFor(level: number, seed: number, aggressive: boolean): Skill The frozen skill for a level (clamped to 1–10), a seed and a style. It reads ladder[level - 1] directly, with no fallback.
  3. 26depthFor(pos: Position, skill: Skill): number The depth limit for this position: the rung’s depth, plus one on a hashed share of positions.
  4. 27judge(pos: Position, skill: Skill): Score The evaluation in the skill’s style plus any blunder. This is what the search scores a leaf with.
  5. 28blunder(pos: Position, skill: Skill): Score The occasional misjudgement: on a hashed share of positions, up to ±blunderWindow centipawns.
  6. 29seesMove(after: Position, skill: Skill, move: Move, ply: number): boolean Whether the player notices a move. Vision fades with ply, and captures and checks get a second chance.
  7. 30overlookedRootMoves(pos: Position, skill: Skill, rootMoves: Pv): Move[] The root moves the player misses. If it would miss every one, it sees them all.
  8. 31randomMove(pos: Position, skill: Skill, moves: Pv): Move Level 1’s move: mate in one if there is one, otherwise a hashed random choice.
  9. 32givesMate(pos: Position, move: Move): boolean Whether a legal move checkmates.
  10. 33mix32(x: number): number A 32-bit integer hash finaliser that scrambles bits.

S3 Evaluation

  1. 34psqBonus(pieceType: PieceType, f: File, r: Rank): readonly [mg: Score, eg: Score] The placement bonus for a white piece of this type on this file and rank, for the middlegame and the endgame.
  2. 35pieceSquareTables(): readonly [mg: PsqTable, eg: PsqTable] Tables of psqBonus for every piece and square, indexed piece * 64 + index64(sq). Black’s are mirrored with flipRank and negated.
  3. 36kingDistances(): DistanceTable new King moves between any two squares, indexed by index64 and computed with fileOf and rankOf.
  4. 37evaluate(pos: Position, style: Style): Score Static evaluation in centipawns for the side to move: material, placement and the style’s king-attack term, tapered from middlegame to endgame. It walks SQUARES.

S4 Chess rules and position

  1. 38makeMove(pos: Position, move: Move): Position | null The position after a move, or null if it leaves the mover’s king in check. pos is not changed. search, qsearch, legalMoves and perft call it.
  2. 39makeLegalMove(pos: Position, move: Move): Position new For callers that already know the move is legal: givesMate, overlookedRootMoves, perftDivide and parsePosition. They need no null check.
  3. 40lift(draft: Draft, sq: Square): Piece Takes a piece off a square, keeping the counts and key in step.
  4. 41put(draft: Draft, sq: Square, piece: Piece): void Puts a piece on a square, keeping the counts, king squares and key in step.
  5. 42inCheck(pos: Position): boolean Whether the side to move is in check.
  6. 43isDraw(pos: Position): boolean A draw by the fifty-move rule, a repetition or insufficient material. The repetition walk is bounded by min(halfmoveClock, gamePly), so it needs no ?..
  7. 44parseFen(fen: string): Position A new position, with no history, from a FEN string.
  8. 45castlingFromFen(board: Board, kingSq: KingSquares, field: string): { castlingRights: Rights; castle: Castle } Reads the FEN castling field in KQkq, Shredder-FEN or X-FEN form, so Chess960 is covered.
    1. 45.1outermostRook(rank: Rank, rook: Piece, edge: File, kingFile: File): File The file of the outermost rook between the edge and the king, or −1. It takes a rank, not a 0x88 rankBase.
  9. 46hasRight(castlingRights: Rights, right: Right): boolean new, optional Whether a castling right is held.
  10. 47isKingside(right: Right): boolean new, optional Whether a castling right is kingside.
  11. 48toFen(pos: Position, chess960: boolean): string The position as a FEN string.
  12. 49moveToUci(move: Move, chess960: boolean): string A move in UCI notation, such as “e2e4”. Castling is written king-takes-rook in Chess960.
  13. 50parseMove(pos: Position, str: string, chess960: boolean): Move The legal move written as str, or NO_MOVE. Castling is accepted in either notation.
  14. 51legalMoves(pos: Position): Move[] The legal moves.
  15. 52generateMoves(pos: Position): Move[] The pseudo-legal moves. makeMove checks king safety. Pawns advance by PAWN_STEP; other pieces use PIECE_OFFSETS, which has empty arrays, not null, for “none” and pawns.
    1. 52.1pawnMove(from: Square, to: Square, moveType: MoveType): void Adds a pawn move to the list, expanding a move to the last rank into its four promotions.
  16. 53isSquareAttacked(board: Board, sq: Square, by: Colour): boolean Whether a colour attacks a square. It decides which sliders attack along a ray from the offset table, not by comparing offsets with ±16 or ±1.

S5 Zobrist hashing

  1. 54zobristKeys(seed: number): { zobPiece; zobCastle; zobEp; zobSide: Key } stored as Float64Arrays of 16 × 64 (by piece * 64 + index64), 16 (by Rights) and 8 (by File) The random 46-bit numbers that are summed into a position’s key, drawn from a fixed-seed xorshift generator. It still draws 128 per piece, in 0x88 order, and keeps the 64 on-board ones, so every key stays the same (bench 2,047,901).
    1. 54.1rand32(): number The next 32-bit xorshift number.
    2. 54.2rand46(): Key 46 random bits: 32 low bits from one draw and 14 high bits from the next.
  2. 55keyLow(key: Key): number A key’s low 32 bits, used by the skill hashing.
  3. 56keyHigh(key: Key): number A key’s bits above the low 32.

S6 UCI

  1. 57isGoNumber(key: string): key is GoNumber Type guard: whether a word is one of the numbered “go” fields.
  2. 58newSession(): Session The starting position at level 10, aggressive, not Chess960.
  3. 59uciCommand(session: Session, line: string, io: Io): Session Handles one UCI command line and returns the session for the next one.
    1. 59.1onInfo(info: Result): void Prints a UCI “info” line for each depth that finishes during “go”.
  4. 60parsePosition(spec: string, chess960: boolean): Position The position from the arguments of a “position” command: “startpos” or a FEN, then any moves. Unknown moves are skipped.
  5. 61parseGo(tokens: readonly string[]): Go The numbers and flags of a “go” command. Unknown words are skipped.
  6. 62infoLine(result: Result, chess960: boolean): string The UCI “info” line for one finished depth.
  7. 63perft(pos: Position, depth: number): number Counts the leaf nodes to a depth, as a test of the move generator.
  8. 64perftDivide(pos: Position, depth: number, chess960: boolean, io: Io): void Prints the perft count under each root move, then the total and the speed.
  9. 65bench(depth: number, io: Io): void Searches a fixed set of positions at level 10. The total node count is the signature OpenBench reads.
    1. 65.1shouldStop(): false Never stops the search.
    2. 65.2onInfo(): void Discards the per-depth reports.
  10. 66printBoard(pos: Position, skill: Skill, chess960: boolean, out: (line: string) => void): void The “d” command: prints the board, FEN, key and evaluation.

Start-up and I/O

  1. 67Main thread, command-line bench Runs bench directly, without a worker.
    1. 67.1io.out(line: string): void Prints to stdout.
    2. 67.2io.shouldStop(): false Never stops.
  2. 68Main thread, UCI loop Reads stdin and handles stop, quit and isready during a search itself; it passes everything else to the worker.
    1. 68.1worker.onmessage(e: MessageEvent<string>): void Prints the worker’s output and notes when a search ends.
    2. 68.2(async () => …)(): Promise<void> The stdin loop. It sets the shared stop flag for “stop” and “quit”.
  3. 69Worker Keeps the session and runs uciCommand for each line it receives.
    1. 69.1io.out(line: string): void Posts a line to the main thread.
    2. 69.2io.shouldStop(): boolean Reads the shared stop flag. The flag starts as a zeroed Int32Array on its own SharedArrayBuffer rather than null, so there is no null check.
    3. 69.3self.onmessage(e: MessageEvent<string | { stopFlag: Int32Array }>): void Handles a command line, or replaces the stop flag with the main thread’s shared one.
